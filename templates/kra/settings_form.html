Which backend?

KRA eTIMS OSCU

Direct and online: this server talks to KRA's eTIMS service itself. KRA must approve the integration first (vetting), and each branch is a device KRA registers.

KRA VSCU

KRA's virtual control unit (a Java JAR) runs on your own server and signs receipts there. Enter its address as the base URL, e.g. http://localhost:8088.

Pergamon (Easy Tax)

A KRA-approved integrator. Enter the fiscal endpoint and API key Pergamon issues you. Their API is not public, so the adapter posts KRA's canonical payload to that endpoint.

Built-in simulator

Applies KRA's rules in-process for testing and training. Nothing leaves this server; receipts are not valid with KRA.

Tax types

Map →

Every tax rate must map to a KRA letter: A exempt, B 16%, C zero-rated, D non-VAT, E 8%. A 0% rate is ambiguous, so check it.
